# Oryginalne komentarze przykładów

Pliki `*_original.txt` zachowują komentarze z wersji b7a5d54, w tym dawne schematy
tekstowe i opisy historyczne. To materiały archiwalne: równania bloków, skalowanie,
upływ i instrukcje uruchomienia zastępują aktualne [specyfikacja](../reference_pl.md),
[instrukcja](../usage_pl.md) i [objaśnienia przykładów](../advanced_examples_pl.md).
Nie należy dołączać tych plików dyrektywą `.include` ani używać ich jako specyfikacji
do generowania nowych obwodów. Autor oryginalnych przykładów: Dariusz Domal.
